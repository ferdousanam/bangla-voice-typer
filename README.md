# Bangla Voice Typer (বাংলা ভয়েস টাইপার) 🎙️

একটি সম্পূর্ণ ফ্রি, ওপেন সোর্স এবং ডিসট্র্যাকশন-ফ্রি (বিজ্ঞাপন ও সাবস্ক্রিপশনহীন) সিস্টেম-ওয়াইড বাংলা ভয়েস টাইপিং টুল। এটি উইন্ডোজের যেকোনো সফটওয়্যার বা অ্যাপ্লিকেশনে (MS Word, Notepad, VS Code, Browser, WhatsApp, Messenger ইত্যাদি) সরাসরি ভয়েস থেকে খাঁটি বাংলায় টাইপ করতে পারে।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Features)

- 🤖 **Gemini AI ইন্টিগ্রেশন (Smart Voice Engine):** গুগলের অত্যাধুনিক `Gemini Flash` মডেলের মাধ্যমে মানুষের মতো অর্থ বুঝে বাংলা টাইপ করা।
  - **অটোমেটিক বিরামচিহ্ন:** কথা থামার সাথে সাথে দাঁড়ি (।), কমা (,) ও প্রশ্নবোধক চিহ্ন (?) স্বয়ংক্রিয়ভাবে বসে।
  - **বাংলিশ ও মিশ্র ভাষা স্বীকৃতি:** বাংলা ও ইংরেজি শব্দ মিলিয়ে বললেও চমৎকারভাবে রূপান্তর করে।
  - **স্মার্ট ফিলার ফিল্টারিং:** অপ্রয়োজনীয় তোতলামি বা "উমম..." নিজে থেকেই বাদ দেয়।
- 🎙️ **ডুয়াল ইঞ্জিন সাপোর্ট:** Gemini Flash AI অথবা বেসিক Google STT (কোনো এপিআই কি ছাড়াই) — যেকোনোটি বেছে নেওয়ার সুবিধা।
- 🎨 **ফিক্সড সাইজ ফ্লোটিং বার (Fixed Floating Bar):** কোনো অটোমেটিক রিসাইজ বা লাফালাফি করবে না। স্ক্রিনের যেকোনো জায়গায় স্থির ও ড্র্যাগেবল অবস্থায় থাকবে।
- 📝 **ডেডিকেটেড আউটপুট ও হিস্ট্রি উইন্ডো (Output History Window):** দীর্ঘ টেক্সট ফ্লোটিং বারে না লিখে আলাদা একটি সুন্দর উইন্ডোতে টাইমস্ট্যাম্পসহ সংরক্ষিত থাকবে, যেখান থেকে এক ক্লিকে সম্পূর্ণ টেক্সট কপি করা যায়।
- 📥 **সিস্টেম ট্রে সাপোর্ট (System Tray):** মিনিমাইজ করলে সিস্টেম ট্রেতে থাকবে এবং ব্যাকগ্রাউন্ডে কাজ করবে। ট্রে আইকনে ডাবল-ক্লিক বা রাইট-ক্লিক করে কন্ট্রোল করা যায়।
- ⚙️ **কাস্টমাইজেশন ও সেটিংস (Settings Panel):**
  - থিম নির্বাচন (💻 সিস্টেম ডিফল্ট, 🌙 ডার্ক মোড, ☀️ লাইট মোড)।
  - গ্লোবাল শর্টকাট পরিবর্তন (ডিফল্ট: `Ctrl + Alt + B`, যা ব্রাউজার বা কোনো সফটওয়্যারের সাথে কনফ্লিক্ট করে না)।
  - ভাষা নির্বাচন (বাংলা - বাংলাদেশ `bn-BD`, বাংলা - ভারত `bn-IN`, ইংরেজি `en-US`)।
  - সাউন্ড বিপ অন/অফ করার সুবিধা।
  - Always on top এবং Auto-hide অপশন।
  - কথা থামার বিরতি (Pause threshold) ও রেকর্ডিং টাইম লিমিট টিউনিং।
- 🛡️ **আইসোলেটেড ভার্চুয়াল এনভায়রনমেন্ট:** প্রোজেক্টের সমস্ত লাইব্রেরি `.venv`-এ আবদ্ধ থাকে, গ্লোবাল পাইথনে কোনো কনফ্লিক্ট তৈরি করে না।
- 🇧🇩 **নিখুঁত বাংলা স্বীকৃতি:** Google Speech Recognition API (`bn-BD`) চালিত।

## 🛠️ ইনস্টলেশন ও ব্যবহার (Installation & Usage)

### সবচেয়ে সহজ পদ্ধতি (স্বয়ংক্রিয়):
সরাসরি **`run.bat`** ফাইলে ডাবল-ক্লিক করুন। এটি নিজে থেকেই:
1. `.venv` ভার্চুয়াল এনভায়রনমেন্ট তৈরি করবে (যদি না থাকে),
2. প্রয়োজনীয় লাইব্রেরিগুলো `.venv`-এর ভেতরে ইনস্টল করবে,
3. এবং সরাসরি অ্যাপ্লিকেশন চালু করে দেবে!

---

### টাইপ করার নিয়ম:
1. যেকোনো সফটওয়্যার (Notepad, Word, Chrome, ইত্যাদি) ওপেন করে কার্সার রাখুন।
2. **শুরু করতে:** কিবোর্ডে চাপুন **`Win + Space` দুবার (Win + Double Space)** — সাথে সাথে বিপ সাউন্ড হয়ে রেকর্ডিং শুরু হবে।
3. নিশ্চিন্তে বাংলায় কথা বলুন — মাঝে বিরতি নিলেও রেকর্ড বন্ধ হবে না।
4. **থামাতে:** কথা শেষ হলে কিবোর্ডে চাপুন **`Win + Space` একবার**।
5. সাথে সাথেই সম্পূর্ণ বক্তব্যটি দাঁড়ি-কমাসহ নিখুঁত বাংলায় কার্সারের স্থানে টাইপ হয়ে যাবে এবং **📝 আউটপুট উইন্ডো**-তেও সেভ থাকবে!
*(নোট: ফ্লোটিং বারের 🎤 / ⏹️ বাটনে ক্লিক করেও যেকোনো সময় শুরু বা বন্ধ করা যাবে। এছাড়া ব্যাকআপ শর্টকাট হিসেবে `Ctrl + Alt + B`-ও কাজ করবে।)*

---

### ম্যানুয়াল পদ্ধতি (টার্মিনাল থেকে):

1. **ভার্চুয়াল এনভায়রনমেন্ট তৈরি ও সক্রিয় করুন:**
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\activate
   ```

2. **ডিপেন্ডেন্সি ইনস্টল করুন:**
   ```powershell
   pip install -r requirements.txt
   ```

3. **অ্যাপ্লিকেশন রান করুন:**
   ```powershell
   python main.py
   ```
